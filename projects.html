BBAutomorphisms

Supporting work for a paper on automorphisms of bivariate bicycle error-correcting codes. SAGE code for computationally verifying the forward problem (given polynomial pair (A, B) → Aut(R)) and the inverse problem (given a target Aut(R) or encompassing subgroup H → (A, B)).

rust_kernel

An operating system written entirely in Rust, with the longer-term goal of running the video game Rust in Rust.
